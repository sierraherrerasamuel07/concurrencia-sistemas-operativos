
# Concurrencia y Sincronización en Java - Sistemas Operativos

**Autor:** Samuel Sierra Herrera  
**Institución:** Universidad Santiago de Cali  
**Asignatura:** Sistemas Operativos  
**Docente:** David Parra Cardona  

## Descripción
Este proyecto resuelve el problema clásico de **Productor-Consumidor** aplicando tres mecanismos de sincronización (Monitores, Semáforos y Mutex explícito) desacoplados a través de la interfaz `BuferCompartido`. Incluye además demostraciones independientes de **Barreras** (`CyclicBarrier`) y del **Algoritmo de Peterson** para exclusión mutua.

## Requisitos
- Java Development Kit (JDK) 17 o superior.

## Instrucciones de Compilación y Ejecución

para ejecutar el programa en cualquier entorno con JDK 17 o superior, clone el repositorio con git clone [https://github.com/sierraherrerasamuel07/concurrencia-sistemas-operativos.git](https://github.com/sierraherrerasamuel07/concurrencia-sistemas-operativos.git), compile los archivos en la terminal con javac *.java y ejecute la clase principal mediante el comando java Main (o abra la carpeta desde su IDE de preferencia como VS Code y ejecute directamente la clase Main.java) para interactuar con el menú de consola que coordina todas las pruebas.
